## ❌ BLOQUEIO ACTIVO

### Apify MCP — não carrega no Claude Desktop (Store)
**Causa provável:** Claude Desktop instalado via Microsoft Store roda em sandbox (WindowsApps). O sandbox bloqueia execução de processos externos (`npx`) mesmo com caminho completo.

**Solução definitiva [PRÓXIMA SESSÃO]:**
```
1. Desinstalar Claude Desktop da Microsoft Store
2. Baixar instalador .exe directo em: https://claude.ai/download
3. Instalar versão não-sandboxed
4. O claude_desktop_config.json já está criado — vai ser lido automaticamente
5. Testar Apify na nova instalação
```

**Alternativa temporária:** usar o `PlanoChave_IntelDashboard.html` para Reddit enquanto Apify não está operacional.
